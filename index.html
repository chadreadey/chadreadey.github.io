Evidence Gap Mapper Source code private

Give it a drug; it maps the published evidence into an outcome × study-design matrix and flags the empty cells as candidate research gaps.

Problem
Health-economics and outcomes researchers need to see quickly where evidence on a drug is thin before planning new studies.
What I built
Sole developer: retrieval from PubMed and ClinicalTrials.gov, LLM screening and classification, a deterministic matrix builder, and the web app.
How gaps are found
An LLM screens and classifies each record by outcome and study design. The matrix is then computed from those labels, and a gap is an empty primary-evidence cell. It means nothing was found in the retrieved, classified records, not that no research exists.
Evaluation
An evaluation harness and accuracy targets are defined; the gold-standard set needed to measure error rates is still being built, so no accuracy figure is claimed yet. Measured runs take about 23–177 seconds per drug.
Stack
TypeScript, Claude, NCBI E-utilities, ClinicalTrials.gov API, Railway

NBA PER: Leakage Audit & Forecast

I re-examined a group project's headline result, showed it came from leakage, and replaced it with an honest next-season forecast.

Problem
A 2023 group project (with Carli Kelley and Garner Hasler) reported a test MAE of 0.35 PER points, against a PER standard deviation of about 4.7. Was that prediction?
What I found
Mostly formula recovery. PER is computed from the same season's box score the model was given, plus composites built from it (BPM, Win Shares, VORP). Out-of-time splits barely changed the error, removing the composites raised it to 1.34, and traded players' near-duplicate rows crossed the random split.
What I built
My own 2026 refresh with a real task: forecast next season's PER from what's known at season's end. Rolling-origin backtest over four 5-season windows, time-ordered CV for model selection, player-cluster bootstrap intervals, and pinned, checksummed data that one command reproduces.
Evaluation
Across 6,184 player-seasons, the CV-selected model beats the baseline by 0.11 MAE (about 5–6%). It does not hold in 2022–26, where it is slightly worse; ridge would have won there, but picking it after seeing the test set would be selecting on the test set.
Stack
Python, pandas, scikit-learn, uv, Modal

MLB Pitch Classification

Predicting the umpire's ball/strike call from pitch location, the batter's own strike zone, and the count, with an interactive strike-zone demo.

Problem
How much do location, the batter's height-specific zone, and the count shift whether a taken pitch is called a strike?
What I built
A rebuild on Statcast data: a pipeline that pulls every called pitch from 2022–2026, and a logistic model that measures location relative to each batter's own zone. I also built the interactive demo. The original 2019 analysis was a 2023 group project with Carli Kelley and Garner Hasler.
Evaluation
Trained on 1.42M called pitches from 2022–24 and tested on 708K from the later 2025–26 seasons: 93.4% accuracy, AUC 0.984. The original 2019 feature set scores 92.5% on the same split. Near the edge the call is genuinely uncertain: accuracy is about 64% for pitches within an inch outside the zone.
Demo
The interactive demo still runs the original 2019 model, which predicts any strike (called, swinging, or foul) and reached 82.4% test accuracy. The two numbers are not directly comparable.
Stack
Python, pybaseball (Statcast), scikit-learn, statsmodels, JavaScript canvas

Eliminating Childcare Deserts in New York State

A mixed-integer program that chooses where to expand existing childcare facilities and build new ones so that no New York ZIP code is a childcare desert, at minimum cost. Constraints cover expansion caps with tiered costs, small/medium/large new sites, coverage targets for children 0–12 (higher in high-demand ZIPs), a separate 0–5 coverage target, and minimum spacing between new sites.

I built the data pipeline (15,604 licensed facilities, 215,400 candidate sites, 1,646 ZIP codes) and the Gurobi model with a classmate. Status: the full-state model is formulated, but it exceeded our size-limited Gurobi license, so there is no solved allocation yet.
